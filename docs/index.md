# Alyvo Engineering

O Alyvo é um assistente administrativo para **uma única clínica**. Este portal reúne os primeiros passos, a arquitetura do sistema e suas decisões técnicas registradas como ADRs.

- API HTTP: `/api/v1`; referência Scalar local: `http://localhost:8000/docs`.
- Portal local: `http://localhost:8001`, publicado pelo Docusaurus.
- Decisões estruturais: [ADRs](decisions/0001-modular-monolith.md).
- Visão técnica: [arquitetura](architecture/overview.md).

Dados de exemplos e seeds são exclusivamente sintéticos.
